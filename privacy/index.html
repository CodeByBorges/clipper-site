Política de privacidade

Última atualização: 24 de outubro de 2026.

O Clipper é uma ferramenta de uso pessoal que roda apenas no computador do seu operador.

Dados acessados

  • Do TikTok: o identificador da conta, o nome de usuário e o token de acesso concedido no login, usados apenas para publicar vídeos na conta do próprio operador.
  • Dos vídeos de origem: o áudio e a transcrição, usados apenas para escolher os trechos dos cortes.

Armazenamento

O token de acesso e os vídeos gerados ficam salvos apenas no computador do operador. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Serviços de terceiros

A transcrição dos trechos candidatos é enviada à API da OpenAI para seleção dos melhores momentos. A publicação usa a API oficial do TikTok.

Remoção

O acesso pode ser revogado a qualquer momento nas configurações do TikTok, em Segurança > Aplicativos e serviços. Apagar o arquivo de token local remove todos os dados guardados.
